# VoiceCover - App Android Nativa (Kotlin + Jetpack Compose)

Arquitectura real:
[App Android] -> [Backend FastAPI GPU con RVC + Demucs] -> MP3 final

La app sola NO puede entrenar voz ni separar pistas, necesita servidor con GPU.
Incluye: app/ + backend/main.py
